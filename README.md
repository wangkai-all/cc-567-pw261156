# 分段计量结算系统（本地实现，仅用 Node.js 内置模块）

居民表与公共区域表分开计量；账期内存在**总表换装**与**单位倍率变化**。
入仓（结算）时按变更时刻把账期拆成账段，逐段用**当时生效倍率**折算电量；
查询端既能跑不落地的新估算，也能回查冻结的已结批次；倍率修正只追加调整批次，不改写快照。

## 运行

```bash
node server.js            # 端口默认 3000
PORT=8080 node server.js  # 读取 PORT，绑定 127.0.0.1
npm test                  # node --test，35 个用例（正常 + 异常）
```

打开 `http://127.0.0.1:<PORT>`，页面业务结果区节点带
`data-evidence-result` 属性，其值随每次实际处理变化，便于核对操作前后内容。

## 合成数据（可复现）

`lib/synthetic.js` 生成两期各 48 小时的逐时读数：

| 时刻（UTC） | 事件 |
| --- | --- |
| 2026-10-02 10:00 | 旧总表 CT 倍率 10 → 12 |
| 2026-10-02 10:30 | 旧总表拆除、新总表换装（倍率 15，起度 300） |

两个事件在**同一时钟小时**内，使该小时被切成两段（10:00–10:30 旧表 / 10:30–11:00 新表），
引擎要求两段首尾相接、不重不漏。数据另附独立真值 `groundTruth`（不参与计费，只用于对账测试）。
`buildSyntheticData({ dropReading: true })` / `{ reverseReading: true }` 可制造缺读数、表盘倒走异常。

## 核心口径

- **拆账**：相邻读数配对成账段；账段 `(t1, t2]` 左开右闭，事件落在 `t2` 归属本段、落在 `t1` 归属新段；
  段内出现倍率事件却无切点读数时报 `MULTIPLIER_CHANGE_INSIDE_INTERVAL`。
- **电量**：`账段电量 = 表盘差 × 当时倍率`；换装旧表末读与新表首读必须在换装时刻相接
  （`REPLACEMENT_HANDOFF_GAP` / `REPLACEMENT_INITIAL_DIAL_MISMATCH`）。
- **分摊**：`线损 = 总表电量 − 居民合计 − 公共电量`，仅按居民电量比例分摊（最大余数法闭合）；
  公共区域独立成列，不承担居民线损。
- **结算快照**：`settlePeriod` 冻结整份账本（`Object.freeze` 深冻结），重复结算报
  `BATCH_ALREADY_SETTLED`；居民行支持 `carryIn/carryOut` 结转，公共行不结转。
- **补交**：`supplementMultiplier` 深拷贝输入后重算，差额只追加 `ADJ` 调整批次；
  同一修正重复提交报 `ADJUSTMENT_ALREADY_EXISTS`。
- **重算量对照**：方案 A 分段读数重算（读数配对、倍率查询、边界校验、表盘运算全部发生）；
  方案 B 直接读已结快照（零表盘运算，仅 O(结果行) 读取），同输入下两方案结果严格一致。
- **错误对照算法**：`buildNaiveLedger` 复现"整月表盘差 × 月底倍率"的禁止做法，
  页面「对照分摊明细」逐段展示其误差如何沉淀为虚增线损并转嫁给居民。

## 页面三个业务按钮

1. **结转样例账期**：P0 结算（R1 不付清）→ P1 结算，展示 R1 的 `carryIn` 接续。
2. **补交倍率变动**：对已结 P1 追加"新总表 15→20"调整批次，原快照保持冻结。
3. **对照分摊明细**：分段算法 vs 月底倍率朴素算法，含同小时两段相接核对与望远镜对账。

所有数字均由服务端实际处理得出，页面只做渲染。

## 目录

```
server.js            HTTP 服务（node:http，127.0.0.1，读 PORT）
lib/domain.js        常量、错误码、倍率生效规则
lib/synthetic.js     可复现合成数据（含异常夹具）
lib/engine.js        拆账引擎、朴素对照算法、相接性/望远镜对账
lib/app.js           估算、结算快照、结转、补交、重算量对照
public/index.html    页面（data-evidence-result 业务结果区）
test/                node:test 用例（引擎 / 应用 / HTTP）
```
